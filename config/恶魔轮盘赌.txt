恶魔轮盘赌 · 群友版（复刻 Buckshot Roulette）
================================================

一句话：一把 12 号霰弹枪，弹匣里实弹和空包混着，轮流朝自己 / 朝对方开枪；
朝自己开空包可以继续开枪，谁先被电到 0 谁输。互动全在 panel.py 的按钮面板上。


一、怎么开
----------
  群里发「恶魔轮盘赌」（也认「恶魔轮盘」「轮盘赌」「恶魔轮盘赌菜单」）→ 主菜单，
  **主菜单第二行就是本群榜**。

  主菜单按钮：
    单人·道具 / 单人·纯赌     跟大肥鱼对枪
    公开挑战                  摆一桌，谁先点谁来
    定向挑战                  只是说明：要发「恶魔轮盘赌 @对方」才能点名
    完整榜单 / 玩法规则

  定向挑战：发「恶魔轮盘赌 @阿伟」，机器人发一张挑战帖，**只有阿伟能点接受**，
  接受时自己选道具 / 纯赌。3 分钟没人接就作废。
  公开挑战：除了发起人，谁都能接（先接先得）。

  文字命令兜底：
    「恶魔轮盘赌 榜单 / 排行」   看完整榜单
    「恶魔轮盘赌 规则」         玩法 + 九件道具说明
    「恶魔轮盘赌 状态」         重发当前这局的面板
    「恶魔轮盘赌 结束 / 认输」   这局算弃权（按输结算），直接结算


二、基本规则
------------
  · 双方各 **5 点电**（❤❤❤❤❤）。
  · 弹匣：每轮按下面的数量随机混装（顺序只有枪知道，面板只报实弹 / 空包各几发）：

        第 1 轮  2 实弹 + 1 空包   （3 发）
        第 2 轮  3 实弹 + 2 空包   （5 发）
        第 3 轮  4 实弹 + 3 空包   （7 发）
        第 4 轮起 4 实弹 + 4 空包  （8 发）

  · 朝自己开空包：不扣电，**枪还归你**，可以接着开（核心博弈）。
  · 朝自己开实弹：自己掉 1 点电，交枪。
  · 朝对方开：实弹对方掉 1 点电；空包什么也没有。两种都交枪。
  · 手锯加成：下一发打中的伤害 ×2（打空包不消耗伤害，锯子也一起用掉）。
  · 手铐：对方下一回合直接跳过（被锁的人自己那一回合不会发生）。

  · **弹匣打空只补一轮新弹 + 每人补发 2 件道具，血量不回满、手牌不清空。**
    也就是说前面挨的枪会一直跟着你 —— **一局必须打到有人电量为 0 才结算**。
    这是 v1.1 修掉的 bug：以前每轮结束双方会异常回满血，等于白打。

  · **谁的血量归零谁就输**，对手获胜 —— 包括「朝自己开枪把自己电死」的情况
    （v1.1.1 修掉的 bug：以前自己把自己打空血会被判成赢家）。


三、两种模式
------------
  道具模式：每轮开始每人发 2 件道具（手牌上限 8 件，可跨轮累积）。九件套照原版：

    放大镜 🔍   看一眼当前这发是实弹还是空包
    香烟 🚬     回 1 点电（最多回到满电）
    啤酒 🍺     把当前这发退出来（不击发），能看清它是什么
    手锯 🪚     锯短枪管：下一发打中的伤害 ×2
    手铐 ⛓️     锁住对方：对方下一回合跳过
    逆变器 🔄   把当前这发反转（实弹变空包、空包变实弹）
    电话 ☎️     告诉你弹匣里「从这发数第 N 发」是实弹还是空包
    药丸 💊     50% 回 2 点电 / 50% 掉 1 点电（可能把自己药翻）
    肾上腺素 💉 从对方手里抢一件道具，放进自己手牌

  纯赌模式：一件道具都没有，全看弹匣和胆子。

  跟原版的一处不同：肾上腺素在群里没法「偷来立刻用」（面板一次只能做一件事），
  所以改成抢进手牌，下回合再用。


四、入场门槛费（银币）
----------------------
  钱包和抽卡 / 锻造共用（`data/card_users_official.json` 里的 shards）。
  每人每局入场交 **100 银币**，结算时按模式返还：

    道具模式：赢 → 返 140（×1.4，净赚 40）；输 → 返 0（全赔）
    纯赌模式：赢 → 返 120（×1.2，净赚 20）；输 → 返 50（退一半）

  · 双人局两边**各交各的**，谁赢谁拿自己的倍率，输家按自己的模式退。
  · 余额不够直接开不了局，会告诉你差多少（签到 / 锻造都能攒银币）。
  · **超时散桌不是输**：入场费原路全退。
  · 认输算输，按上面输的规则退。

  想改金额 / 倍率：`qqbot/devil_roulette.py` 顶部的 `ENTRY_FEE` 和 `MODE_RULES`。


五、大肥鱼（单人对手）
----------------------
  · 会看情报：开过放大镜 / 啤酒 / 电话之后，它也会按知道的弹位来决策；
    不知道的时候按「剩下实弹的比例」决定打人还是打自己。
  · 残血会抽烟，会赌药丸；有手铐会先铐你；有手锯会先锯再打；
    知道是空包又很想打你，会先按逆变器。
  · 偶尔会冒一句奶凶的狠话震慑你（比如「你的手在抖吧？我看得清清楚楚喵。」）。
  · **被你电趴下会很不甘心**（「不、不算！刚才那发是我让着你的！」这类台词）。


六、榜单
--------
  · 主菜单第二行、结算面板带本群前三名；「完整榜单」看前十。
  · 排序：胜场多 → 负场少 → 最长连胜。
  · 每局结束记胜负，落盘 `data/devil_roulette_rank.json`（按群分开），重启还在。
  · 单人局只记玩家的胜负（大肥鱼不上榜）；双人局两边都记。
  · **对局过程中的面板不再重复贴榜单**（v1.1 精简），榜单只在菜单 / 结算里看。


七、面板排版（v1.1 精简过）
--------------------------
  只用 QQ markdown 支持的语法，靠字号和留白分层：

    # 一号标题        → 面板标题（最大）
    正文              → 血量 / 弹匣 / 回合 / 手牌，一行一件事
    *** 分割线        → 隔开战况和台词
    > 块引用          → **大肥鱼的话单独放这里**（客户端会缩成小字灰底）

  面板里最多出现三行战况：「你的上一手」「大肥鱼上一手」「换弹 / 被锁小播报」，
  过程细节不往面板上糊。对局面板控制在 10 行以内。


八、群里的一个取舍：情报是全群可见的
------------------------------------
  QQ 群机器人没有私聊，放大镜 / 电话看到的东西只能写在公开面板上。
  所以双人局里**情报要当公开牌打**：先看到的人先动手，后面的人知道得晚一点。
  这不会影响单人局（大肥鱼本来就知道自己看到的东西）。


九、会话与超时
--------------
  · 一个群同时只有一桌（避免两拨人抢同一张面板）。
  · 30 分钟没人动自动散桌（入场费全退）；挑战帖 3 分钟有效。
  · 对局只在内存里，重启机器人就散场（和 CS、弗一把一样），榜单才落盘。
  · 旧面板（点过的、被新面板顶掉的）再点会提示「看最新发的那条」。

          ENTRY_FEE / MODE_RULES（入场费与倍率）、AI_MAX_STEPS / TAUNT_CHANCE，
