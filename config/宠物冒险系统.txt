宠物冒险：把锻造系统锻造出来的剑交给宠物（大肥鱼），闯一座 8 位面 × 5 层的位面塔。
肉鸽规则，全程走消息面板交互；数值口径以本文件为准（实现见 qqbot/pet_sword.py 与
qqbot/pet_sword_data.py，改完代码记得一起改这里）。

====================================
一、剑从哪来
====================================
1. 锻造收工（淬火后出测试结果）的那把剑，除了照旧把总价值打进银币余额，还会额外登记进剑库；
   银币是收益，剑是额外留下的装备。
2. 剑记录：刀型、图案、材料、强度/硬度/韧性、测试分数、磨损档位、总价值、锋利度。
3. 剑库每人一份，落盘 data/pet_swords_official.json；最多保留 24 把，超出时把价值最低、
   且没装备的那把折成一半价值加进钱包。
4. 剑的数值：
   - 锋锐（攻击）=（0.6×强度 + 0.4×硬度）× 图案加成，四舍五入，最低 1；
     图案加成 = 0.8 + 0.2×√图案倍率（倍率 0.8 → 0.98，6.0 → 1.29，15.0 → 1.57）。
   - 坚韧（减伤）= 韧性 × 磨损倍率，最低 1。
   - 锋利度上限：崭新出厂 100，战痕累累 50（按磨损倍率 0.85~1.15 线性折算）。
5. 锋利度不再是“每砍一刀掉一点”，而是**每打完一场战斗掉一截**（见第六节），
   掉到 0 就是卷刃：攻击只剩 60%，必须磨刀才能恢复。

====================================
二、位面与层
====================================
共 8 个位面，每位面 5 层，合计 40 层；第 5 层固定是首领战。

  位面1 浅潮滩      位面2 珊瑚坟场    位面3 锈铁深渊    位面4 沉船墓域
  位面5 幽光冰渊    位面6 熔鳞火海    位面7 裂隙星海    位面8 终末鲸落

1. 每层开局刷 2~3 条分支，每条分支在面板上写明“这条路会碰到什么”：
   战斗/精英/首领 会写怪物血量、攻击和预计银币；事件会写第一个选项的大致结果。
2. 分支排布有随机性（“不是每层都一定有休整/事件”）：
   - 混合层（42%）：战斗 / 事件 / 休整 / 商店 / 宝藏里随机抽 2~3 条；
   - 打怪层（26%）：只有战斗和精英（有时再来一场战斗）；
   - 精英层（10%）：精英 + 战斗；
   - 休整层（14%）：休整 + 事件；
   - 商店层（8%）：商店 + 宝藏。
3. 最多 3 条分支，超过平台按钮限制的不会出现（面板最多 5 行 × 5 个）。
4. 打完第 5 层进入下一位面第 1 层；打完第 8 位面第 5 层 = 通关。

====================================
三、怪物与难度
====================================
1. 8 个位面各 5 只怪（3 普通 + 1 精英 + 1 首领），共 40 只，每只都有自己的招式。
2. 数值按“第几关”（第 1 关 = 位面1层1，第 40 关 = 位面8层5）整体放大：
   血量 ×（1 + 0.03 × 关卡序号），攻击 ×（1 + 0.02 × 关卡序号）。
   表里的基础数值本身已经体现普通→精英→首领的差距，所以不再额外乘类型倍率。
3. 参考量级（实机数值会 ±5% 浮动）：第 1 关普通怪约 45 血 / 11 攻；第 40 关普通怪约 270 血 / 52 攻；
   位面1 首领约 160 血 / 18 攻；位面8 首领约 1270 血 / 71 攻。
4. 怪物招式带效果：流血（我方每回合 -3 HP，2 回合）、吸血（按伤害回血）、
   破防（先砍半格挡）、自愈。面板会写出它这一回合的「意图」和预计伤害。
5. 拖久了它会越来越凶：
   - 第 7 回合起，敌人每过一回合攻击 +12%；
   - 首领血量低于 50% 时暴怒，攻击 +20%。
   所以“一直防守”拖不死它，反而会被磨死。
6. 银币：普通 1.0 倍、精英 2.2 倍、首领 4.5 倍，基准 = 14 + 5×位面 + 3×层，再 ±15%。
7. 每个位面首领打完：最大生命 +8，并回复最大生命的 20%。

====================================
四、大肥鱼的数值与招式
====================================
1. 血量上限 = 26 + 坚韧÷2 + 宠物等级×2 + 养成「硬鳞」×8。
   （宠物等级来自 pet.py 的养成，位面塔不消耗体力/心情，只借用等级。）
2. 基础攻击 = 剑的锋锐 + 养成「利齿」×2。
3. 防守：获得 8 + 坚韧÷2 + 养成「鲸息」×4 的格挡，格挡只挡下一回合的一次伤害。
4. 伤害公式：我方一击 = 四舍五入(攻击力 × 招式倍率 × 0.8~1.2) - 四舍五入(敌人攻击 × 0.45)，
   最低 1；敌人一击 = 四舍五入(敌人攻击 × 招式倍率 × 0.8~1.2) - 当前格挡，最低 0。
5. 招式（最多 4 个，靠事件/商店/战利品学）：
   次元鲸斩   2.4 倍伤害，冷却 3
   曼巴鲸肘   3 段 0.6 倍，冷却 2
   白鲨突刺   1.6 倍 + 敌人流血 3 回合，冷却 3
   鲸落震击   1.8 倍 + 获得 6 格挡，冷却 3
   回声吐息   回复 14 HP，冷却 3
   潮汐连斩   2 段 1.1 倍，冷却 2
   深渊凝视   敌人攻击 -25%（2 回合），冷却 4
   逆流冲撞   1.3 倍；敌人血量低于 40% 时翻倍，冷却 3
   鲸歌安魂   回复 8 HP + 清除自身流血，冷却 4
   湮灭一掷   3.2 倍伤害，但自己 -8 HP，冷却 5
6. 默认招式「挥剑」1.0 倍、无冷却，永远可用。
7. 招式栏 4 格满了会弹「装不下」面板：放弃新的，或换掉一个。

====================================
六、锋利度与磨刀
====================================
1. 每打完一场：普通 -4、精英 -6、首领 -10；撤退 -2；阵亡再 -3。
   养成「护刃」每级再 -8% 消耗。
2. 磨刀：把锋利度补到上限，每点 3 银币（最少 30）；「磨刀匠指环」打七折。
3. 休整节点可以**免费**磨刀；商店也能花钱磨。
4. 目标手感：走完一趟（40 层、约 26~30 场战斗）磨刀 1~3 次；锋利度掉到 0 会卷刃，
   攻击只剩六成，所以别硬撑到 0。

====================================
七、局外养成（鲸鳞）
====================================
1. 鲸鳞来源：每通过一层 +1，每个首领 +3，通关再 +10，局内银币每 150 折 1；
   大挑战胜利 +12。
2. 「宠物 养成」里消费鲸鳞，永久升级（下一趟生效）：
   硬鳞（最大生命 +8/级，2/4/6 鲸鳞）、利齿（基础攻击 +2/级，2/4/6）、
   护刃（锋利度消耗 -8%/级，2/4/6）、起手（开局多带 1 件道具，3/6）、
   慧眼（商店价格 -15%/级，3/6）、鲸息（每场战斗开始 +4 格挡/级，3/6）。
3. 升级进度跟着存档走，重启不丢。

====================================
八、结算：鲸鳞 + 宠物经验
====================================
1. 冒险带回的奖励是**鲸鳞**和**宠物经验**，不再发银币；局内银币留在局里
   （商店、磨刀用），结算时按每 150 局内银币折 1 鲸鳞。
2. 鲸鳞 = 每通过一层 +1、每个首领 +3、通关 +10，再加局内银币折算。
3. 宠物经验按**每场战斗用了几个回合**算，越利落给得越多：
   - 单场底子：普通战斗 5、精英 12、首领 30；
   - 回合倍率：≤2 回合 ×2.0、≤5 回合 ×1.5、≤8 回合 ×1.2，再慢 ×1.0；
   - 通关额外 +120 经验。
   例：2 回合干掉的首领 60 经验，拖到 9 回合只有 30。
4. 阵亡：鲸鳞和经验**都只带回一半**；收工/通关：全额带回。
5. 经验直接加到宠物身上（可能连升多级，宠物等级影响位面塔的血量上限）。
6. 战迹记录：出征次数、累计宠物经验、单趟最多经验。
7. 大挑战的奖励同口径：胜利给 12 鲸鳞 + 80 经验×回合倍率，不再发银币。

   - 战斗面板写敌人意图、预计伤害、自己的血/格挡/冷却；
   - 行囊写每个道具的效果、是否一次性、是否限战斗；遗物写完整的正负效果；
   - 养成写当前等级、下一级价格、每级效果。

====================================
十、存档
====================================
1. 落盘 data/pet_swords_official.json，每人一份：剑库、战迹、鲸鳞与养成、正在打的那一趟。
2. 正在打的那一趟会保存进度（位面/层/血量/道具/遗物/招式/分支），重启后接着打。
3. 面板序号只在内存里：重启后旧面板的按钮一律作废，发「宠物 冒险」重新唤一张即可。
4. 通关后「待存档」的快照会落盘（pending_save）：重启也不会把“要不要存档”弄丢，直到
   你选择存入或「不保存」为止。

====================================
十一、通关存档（3 个栏位）
====================================
1. 通关（打完第 8 位面第 5 层的首领）之后，面板会先问要不要存档；
   存的是**打最后那个首领之前**的状态：位面8第5层、血量、剑（锋锐/坚韧/锋利度）、
   招式与冷却、道具、遗物、本局加成。
2. 存档栏位 3 个：空槽直接存，已占用的会先弹「覆盖？」面板（覆盖 / 取消），
   取消就回到存档面板，可以换个空槽存，或者选「不保存」。
3. 每档记录：剑名、锋锐、血/血上限、存档时间、挑战胜/负场。
4. 存档落盘，重启不丢；同一档可以反复拿来挑战，不会被消耗。
5. 最多 3 档，满 3 档时每次通关都要自己决定覆盖哪一档（或者不存）。

====================================
十二、哦鲸鲸大挑战
====================================
1. 入口：宠物 挑战 / 宠物挑战 / 哦鲸鲸大挑战 / 大挑战，首页也有「大挑战」按钮。
2. 用任意一档通关存档开局，**每次随机出现三位首领之一**；不消耗存档、不消耗剑的耐久，
   胜负都会记进该档的挑战战绩。
3. 三位首领（期望难度高于位面塔首领，血量 2600~3000 为主）：
   - **海德软脚虾**（320 血 / 60 攻）：血量跟小怪差不多，一阶段被打空会**锁血**，
     直接切换成**二阶段 · 北国沙鹰虾**（1800 血 / 72 攻）；二阶段每隔一回合进入
     「防御」姿态，这一回合它会**反弹玩家这一击的伤害**（玩家自己掉血、它只掉一点），
     并且它不出手 —— 玩家这回合点「防守」就不会受到任何伤害。
   - **显卡吞噬者老黄**（2600 血 / 70 攻）：它的攻击有 **45%** 概率让玩家**麻痹**；
     被麻痹时，玩家下一次「防守」失效（格挡为 0）。面板会提示「被麻痹」。
   - **川建国**（3000 血 / 66 攻）：玩家的每次攻击有 **20%** 概率被**弹开**（这一击不造成伤害），
     并且它每回合回复 **3%** 最大生命。
4. 挑战胜利：鲸鳞 +12、宠物经验 80×回合倍率（≤2 回合 ×2）；失败或撤退：没有奖励。
5. 挑战不吃位面塔的「拖回合加伤」（第 7 回合起 +12%），但首领自己的机制会越来越难受。

====================================
十三、鲸鳞兑换（场外）
====================================
入口：宠物 兑换 / 宠物兑换 / 鲸鳞兑换 / 兑换，首页也有「兑换」按钮。

1. **启程资金**（永久升级，最多 3 级）：每级让**每趟冒险开局多 80 局内银币**，
   升级花费 25 / 40 / 60 鲸鳞。局内银币可以用来在商店买东西、商店磨刀。
2. **兑换道具**：买下来放进仓库，下一趟冒险开局自动带入道具栏（最多 2 件，
   和养成「起手」共用格子）。仓库里的东西用一件少一件。
   疗伤牛奶 12、磨刀石 10、深海护符 15、幸运鳞片 18、回响贝壳 14（鲸鳞）。
3. 鲸鳞不够会明确拒绝；启程资金满级后再点会给提示。
4. 兑换面板会显示：当前鲸鳞、启程资金的等级与下一级价格、仓库里还有什么、
   每件道具的效果（含是否一次性 / 限战斗）。

====================================
十四、数值事件（v2.14 新增）
====================================
除了“拿道具/遗物/银币”的事件，还加了一批**直接改数值**的事件；每个选项后面写清
数值变化，正负都标出来。全部是围绕大肥鱼冒险的短场景：

  热泉疗养      泡一会儿：最大生命 +12、回复 15 HP（纯正面）；喝一口：回复 20 HP
  鲸骨铭刻      刻上名字：攻击 +12%、最大生命 -8；磨掉旧痕：锋利度 +15
  鲨群围猎      抢食：攻击 +10%、自己 -12 HP；让开：40 银币
  脂肪储备      吃个够：最大生命 +20、攻击 -6%；留一点：回复 15 HP
  深海压强      硬扛：坚韧 +10、最大生命 -6；上浮：回复 10 HP
  蜕鳞          蜕掉：坚韧 +8（纯正面）；收集旧鳞：55 银币
  老鲸的馈赠    接受祝福：攻击 +5（固定值，纯正面）；陪它游：回复 25 HP、最大生命 +6
  沉船哑铃      举两下：攻击 +8（固定值）、锋利度上限 -8；当废铁卖：65 银币
  深渊回声      回应它：攻击 +20%、最大生命 -20；堵住耳朵：回复 12 HP
  磨刀祭        磨一磨：锋利度上限 +10（纯正面）；拿走石头：获得「磨刀石」
  饱食珊瑚      吃：最大生命 +10、回复 10 HP（纯正面）；打包：30 银币
  破釜沉舟      拼命：攻击 +25%、当前最大生命 -25%（百分比）；挖开：自己 -10 HP、70 银币

实现上对应的效果键：
  atk_flat   本局攻击 +N（吃百分比加成）
  tough      本局坚韧 +N（防守格挡 = 8 + 坚韧÷2，所以 +10 坚韧 ≈ +5 格挡）
  sharp_max  改锋利度上限（同时把当前锋利度夹回上限）
  max_hp     参数写成 "-25%" 时按百分比改最大生命，整数按点数加
道具额外效果用 ``Item.extra`` 串起来（例如双刃鳞 = 攻击 +12% + 最大生命 -8），
所以“有正有负”的道具和遗物走的是同一套结算。
